# Procera Plant Designer

Procera Plant Designer is a separately installed companion application for Procera.

It provides ATV-DVWK-A 131-based activated sludge process design and can generate Procera PCM project files for subsequent simulation and analysis in Procera.

## Requirements

Procera Plant Designer requires Procera 1.0.1 or later.

## Download

The current public release is:

[Procera Plant Designer 0.1.4](/ETCSoftwareProjects/Procera/releases/tag/plant-designer-v0.1.4)

Download the MSI installer from the release Assets section.

## Installation

Procera Plant Designer is distributed separately from the main Procera installer.

Procera 1.0.1 or later must already be installed before Procera Plant Designer can be installed.

After installation, the **Plant Designer** command becomes available in the Procera main window.
