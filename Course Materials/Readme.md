Each activity includes a structured assignment workbook and may include additional Procera files, supporting materials, and a video briefing.

Users who complete or review an activity are encouraged to submit the short feedback survey linked for each activity. Public activity ratings are based on user feedback.

## Activity Rating

The activity rating is based on the response to:

> **Overall, how would you rate this activity?**

Ratings use a five-point scale.

To avoid displaying unstable ratings based on very small numbers of responses, a public rating is shown only after at least **10 responses** have been collected.

After the minimum response count is reached, the average score is displayed together with the number of responses.

Example:

**★★★★☆ 4.4 / 5 — 37 responses**
